# Parris Piano App — Docs

This `docs/` folder contains project planning and implementation guidance for the Parris Piano repository.

Files:
- `VISION.md` — project vision and goals.
- `ROADMAP.md` — milestones and release plan.
- `ARCHITECTURE.md` — high-level architecture and modules.
- `TO_DO.md` — actionable task list (milestones + tasks).
- `IMPROVEMENTS.md` — current improvement plan and roadmap.
- `DEVELOPMENT.md` — developer onboarding and workflow guide.
- `PROJECT_STATUS.md` — summary of current progress and next steps.
- `CHANGELOG.md` — record of repo improvements made.
- `RECOVERY_NOTES.md` — repo recovery details and sync strategy for this companion copy.
- `spec_original.txt` — original full spec text.
- `ParrisPianoApp.txt` — original small text file.

How to use this folder:
- Read `VISION.md` for long-term product goals.
- Read `ROADMAP.md` for milestone sequencing.
- Use `TO_DO.md` as the current engineering backlog.
- Use `IMPROVEMENTS.md` and `DEVELOPMENT.md` for process and documentation improvements.
